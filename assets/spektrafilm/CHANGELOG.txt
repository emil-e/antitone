Antitone modifications:
- Evaluate the deterministic nonspatial pipeline at build time.
- Retain the source camera-negative and printing-media names.
- Factor characteristic curves, DIR/pre-correction, spectral sensitivities,
  dye/base spectra, input-gamut coordinates and enlarger calibration.
- Share the Hanatos input spectral family rather than installing a full
  camera-negative exposure LUT for every stock.
- Calibrate print time on a controlled neutral AP1 0.18 to output XYZ Y=0.1,
  retaining the frozen complete-rendering reference's printing convention.
  This is a rendering convention, not a photographic or stock-fidelity fit.
- Sample each paper-density readout together with the pinned inverse
  authoring DRT, storing ACEScct/AP1 values.
- Add a positive-to-paper adapter using the existing 0.6 ACEScct/stops
  convention, with a controlled neutral 0.18 anchor.
- Use the historical Academy universal reference and a convex APD-action
  spectral selector for Supra Endura paper-only, with a supplied base prior,
  constant-Y radial adapter boundary and low-positive receiver tangent.
  Retain the scalar neutral log-exposure law, original paper photometry and
  common exposure solve, including the neutral path's tone-dependent tint.
  No output hue/saturation fit or selected-negative characteristic curves
  define this virtual reference. Colour-brightness interaction is deliberately
  compensated. The separate historical APD input is canonically identified;
  its reference-derived components are a private trial with unresolved
  public redistribution clearance, not relicensed by the spektrafilm licenses.
- Target Supra Endura gamut compression directly to the p3rec50 authoring
  reference and omit its separate lightness rolloff. Retain fixed exposure
  calibration independently of output finishing; other media are unchanged.
- Generate compact source conformance observations for native tests.

No source photograph, publisher artwork, Python runtime, grain/halation
profile, camera calibration or measured physical scanner profile is included.
Source hashes, generator identities and numeric component hashes are in
provenance.json. LICENSE-data.txt and LICENSE-code.txt are retained unchanged.
